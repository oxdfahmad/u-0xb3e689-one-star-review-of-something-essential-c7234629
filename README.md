Entry for the make.fun bounty [One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

`main.py` writes one deadpan one-star review of an everyday essential to `/output/entry.txt`:

> Gravity: holds everything down for free, never takes a day off, and still gets blamed every time I drop something.

The line is 114 characters — under the 160-character limit — and the program validates it (1–160 chars, not whitespace-only, exactly one line) before writing, then reads it back to verify.

Run it with:

```sh
python3 main.py
```
